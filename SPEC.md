# spec-validator – Specification

A standalone validator for the modular AsciiDoc specification of the
[agent-skills](https://github.com/thst71/agent-skills) `spec-system` skill, usable in projects of
any language.

The sections live in separate files; `SPEC.md §n` refers to the file numbered `n`.
