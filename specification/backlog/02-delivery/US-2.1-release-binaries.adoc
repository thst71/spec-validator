=== US-2.1 Release binaries and quality gate

Status:: Done (0.1.0) +
Effort:: 3 h +
Traces to:: <<TS-2.1>>, <<FR-2.1>>, <<NFR-2>>

As a maintainer of the agent-skills library, I want checksummed release binaries for every
platform and the documentation of each version, so that projects can pin and verify them
through the library's launcher and readers find the matching documentation.

.Acceptance criteria
. `task check` passes locally and in CI.
. Pushing the signed tag `v0.1.0` publishes the six archives, the four HTML files, the docs
  zip and `checksums.txt`; an unsigned tag publishes nothing.
. The downloaded darwin/arm64 binary reports `0.1.0` with `-version`.

.Test criteria
* Blackbox test (manual, per release): download an archive, verify its checksum, run
  `-version` and validate wos-intel; in a project with agent-skills v0.4.0 or later,
  `.agents/skills/spec-system/bin/validate-specs --update v<version>` pins the release and
  `validate-specs` runs it.
