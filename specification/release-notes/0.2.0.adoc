== Release v0.2.0 (unreleased)

Built with agent-skills v0.4.0.

=== Features

* Acceptance tests in Gherkin feature files: test kinds under `tests` in the configuration
  (`AT`, format `gherkin`, tracing to FR and NFR); every scenario has one unique test ID, its
  trace tags resolve to requirements, and `+<<AT-x.y>>+` resolves in AsciiDoc. Off without
  `tests` (<<US-3.1>>, <<FR-3.1>>, <<FR-3.2>>, <<FR-3.3>>).
* `-test-report results.json` writes the test report master from the Cucumber JSON of a test
  run (<<US-3.2>>, <<FR-3.4>>).

=== Documentation

* The archive names, the archive layout, `checksums.txt` and the `-version` output are the
  interface the agent-skills launcher pins releases by; changing one of them is a major release
  (<<FR-2.1>>). Projects pin a release in their own `.agents/spec-validator.lock` (agent-skills
  v0.4.0 or later), so a release no longer changes the library.
