=== FR-1.5 Configuration

.Acceptance criteria
. The layout (masters, folders, anchor kinds per folder, traceability rules) is read from a
  JSON file: the one named by `-config`, else `.spec-validator.json` in the project root.
. Without a file, the layout of the agent-skills `spec-system` skill applies: requirements
  (FR, NFR), technical specifications (TS), backlog (US) and release notes.
. Unknown fields, an empty document list, invalid or duplicate kinds and rules naming unknown
  kinds are configuration errors.
