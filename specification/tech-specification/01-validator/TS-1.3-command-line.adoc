[[TS-1.3]]
=== TS-1.3 Command line

Implements <<FR-1.6>>, <<FR-1.7>> and <<FR-1.8>>.

* `cmd/spec-validator`, `run(args, stdout, stderr) int` behind `main` for in-process tests;
  flags with the standard `flag` package (`-config`, `-version`, `-fix`, `-masters`,
  `-link <dir>`, `-h`). More than one of `-fix`, `-masters`, `-link` is a usage error.
* Configuration: `-config` if given, else `<root>/.spec-validator.json` if it exists, else
  `DefaultConfig`.
* `-masters` prints `Masters`; `-link` calls `Link` and prints `references linked`; `-fix`
  calls `FixAnchors`, prints the changed files and continues with the validation.
* `version` is set by the release build (`-X main.version`); otherwise the module version of
  `go install …@vX`, else `dev`.
* Exit codes: 0 valid, 1 problems, 2 usage, configuration or read errors.
