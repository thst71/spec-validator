=== TS-2.1 Build and release

Implements <<FR-2.1>>, <<NFR-1>> and <<NFR-2>>.

* `Taskfile.yml` maps the agent-skills task contract: `typecheck` = `go build ./...`, `lint` =
  `golangci-lint run`, `format-check` = `gofmt -l`, `test` = `go test -race -cover ./...`,
  `validate-specs` = `go run ./cmd/spec-validator` (from source: this repository cannot use
  the launcher that pins its own releases), `check` = all of them.
* `.github/workflows/ci.yml`: the gate on ubuntu and macos, `go test ./...` on windows.
* `.github/workflows/release.yml`: on a `v*` tag, GoReleaser v2 (`.goreleaser.yaml`) builds
  with `-trimpath`, `CGO_ENABLED=0` and `-X main.version`, packs the archives with the license
  files and writes `checksums.txt`.
* The agent-skills library is vendored into `.agents/skills/` with `git subtree`; after a
  release, the library's launcher pin is raised to the new version and its checksums.
